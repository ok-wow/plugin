# okWOW

Search and save your okWOW knowledge from your coding agent. The plugin
connects your agent to the okWOW MCP server at `https://api.okwow.ai/mcp` and
adds three skills:

- **recall**: searches okWOW before answering questions about past decisions,
  conventions and project facts, then fetches and cites what it used.
- **save**: saves a verified fact as a memory or a write-up as a document, in
  a destination you choose, and shows the agent how to claim, work and
  complete okWOW tasks.
- **setup**: a guided setup in chat (`/okwow:setup`) for your spaces, people,
  skills and transcripts. It can move your agent's local memory into okWOW
  and make okWOW your agent's default for memory, skills and tasks.

The agent acts as you, with the access you have in okWOW. When the okWOW tools
first connect, your browser opens okWOW: sign in and choose "Read", "Read and
write" or "Manage account". You can revoke the connection at any time in okWOW
under Settings → Authorized apps. An okWOW account is required.

This plugin runs no code on your computer and does not send your sessions to
okWOW. Session capture, which saves your coding sessions as private okWOW
chats, comes with the full plugin at https://github.com/ok-wow/plugin; install
it in place of this one.
